# UI ライティング規約・用語辞書（md-oretools）

## 基本原則

- **対象読者は「遊戯王マスターデュエルのプレイヤー」であり、エンジニアではない。**
- 画面に表示するラベル・見出し・説明文・バッジ・エラーメッセージには、**開発者向け用語・アルゴリズム名・ブラウザ内部 API 名をそのまま出さない**。
- 仕様書（`docs/spec.md`）やコード内の型名・コメントに専門用語があっても、**UI に出力する段階で必ずプレイヤー視点の平易な日本語へ翻訳する**。
- 迷ったときは「技術を知らないプレイヤーが読んで 1 秒で意味がわかるか？」を基準に判断する。

## 再発防止 UI/UX チェックリスト（実装時確認）

1. **数値入力欄**: 枚数・数値入力には原則 `@/components/ui/number-input`（`NumberInput`）を使用し、途中入力の妨害やフォーカス中ホイールによる画面スクロール暴発を防ぐ。
2. **日本語入力（IME）**: Enter キーで確定・追加する入力欄では `e.nativeEvent.isComposing || e.keyCode === 229` を必ず除外する。
3. **破壊的操作・未保存保護**: 削除・初期値リセット・未保存の編集破棄には確認ダイアログを挟む。
4. **エラー・状態の可視化**: 保存失敗や読み込みエラーを握りつぶさず、プレイヤーが次に取るべき行動がわかる日本語メッセージを表示する。
