# md-oretools 仕様書・開発ロードマップ

## 1. コンセプト

[FF14俺Tools](https://ffxiv.es.exdreams.net/) のように、遊戯王マスターデュエルをプレイする上で「自分が欲しい便利ツール」を1つのWebポータルに集約し、段階的に育てていく個人用Webサービス。

- **ブラウザ完結**: 専用ソフトのインストール不要、サーバーコストゼロ。
- **安全な自動化**: ゲームのプロセス・通信には一切触れず、ブラウザの画面共有（`getDisplayMedia`）経由の画面認識のみで完結させる。

---

## 2. 共通仕様（データ永続化・バックアップ・レイアウト）

- **データ永続化方針**:
  - Phase 1 から **IndexedDB（Dexie.js）** に統一してアプリデータ（シミュレータプリセット・誘発カンペ辞書・対戦ログ・自分のデッキ・ROI 設定）を管理する。
  - `localStorage` はサイドバー開閉や最後に開いた画面など、軽量な UI 設定のみに限定する。
- **JSON エクスポート／インポート**:
  - Zod スキーマ＋`schemaVersion` で検証可能な単一 JSON 形式でエクスポート／インポートを行う。
  - インポート時は **「全置換（上書き）」** と **「マージ（ID ベースで追加・更新）」** をユーザーが選択できるようにする。
  - 初期テンプレート（環境テーマ辞書）とユーザー編集データは衝突しないように管理し、編集済みテーマの「初期値に戻す」リセットを可能にする。
- **画面レイアウト**:
  - 通常時はサイドバーから各ツールを切り替える単一ツール表示を基本とする。
  - Phase 3 の実戦利用向けに、**「デュエルモード（画面認識・戦績トラッカー＋誘発カンペの 2 ペイン同時表示）」** を専用ビューとして用意する。

## 3. 主要機能要件

### ① 手札確率シミュレータ

- デッキ枚数（40〜60枚）、初手枚数（先攻5枚 / 後攻6枚など）を指定可能。
- **カードグループ設計（排他グループ前提）**:
  - 1 枚のカードは 1 つのグループのみに属する（全グループの合計枚数 ≤ デッキ枚数）前提とする（例: 1枚初動、2枚初動A、誘発、引きたくないカード等）。
- **初手条件式（DNF: OR of ANDs の 2 階層構造）**:
  - 「条件セット（グループごとの `○枚以上 / ○枚以下 / ○枚ちょうど` の AND）」を複数並べて OR で結合する形式（例: `「1枚初動 ≥ 1 AND 誘発 ≥ 1」OR「2枚初動A ≥ 1 AND 2枚初動B ≥ 1」`）で初手確率を計算する。
- **計算方式（自動切替）**:
  - 基本は **多変量超幾何分布による厳密計算** を自動実行し、グループ数・条件の組み合わせ総数が計算上限を超える場合のみ自動で **高速モンテカルロシミュレーション（既定 10 万回試行）** へフォールバックする（結果画面に計算方式を明示する）。
- よく使うデッキ構成のプリセット保存機能（IndexedDB）。
- **スコープ外（Phase 1）**: 壺系カード（強欲で金満な壺・金満で謙虚な壺等）のドロー／めくり効果は対象外とし、純粋な初手 N 枚ドローのみを扱う。

### ② 誘発カンペ（辞書＆リアルタイム連携）

- **辞書モード**:
  - デッキタイプ（テーマ名）・別名（エイリアス）・代表カード名からの逆引き検索（ひらがな／カタカナ・全角／半角のゆらぎ吸収）で、手札誘発の打ちどころを即座に表示する。
- **誘発メモ構造**:
  - 定番誘発（灰流うらら、増殖するG、無限泡影／エフェクト・ヴェーラー、屋敷わらし、ニビル、墓穴の指名者、ドロール＆ロックバード等）を標準プリセット枠として持ちつつ、**テーマごとに任意の誘発・対策枠を追加可能**にする。
- **自分用メモ編集**:
  - 画面上から各テーマの対策メモや Phase 3 自動類推用の代表カード名リスト（汎用カードを除いたテーマ固有カード）を自由に追記・編集・保存可能（初期値リセット・JSON バックアップ対応）。
- **遊戯王ニューロンリンク**:
  - 登録したカード名（手札誘発および主なカード）に加え、打ちどころ本文・対策ポイント内に登場するカード名も自動ハイライトし、遊戯王ニューロン（公式カードデータベース日本語版）へワンクリックで遷移できるリンクを付与する。収録済みの公式カードID（`cid`）があるカードはカード詳細ページ（`ope=2&cid=...`）へ直接遷移し、未収録カードはカード名検索ページへフォールバックする（`/` 区切りの複合表記はカードごとに個別リンク化）。
- **カード名サジェスト（入力補完）**:
  - 編集画面のカード名入力欄（追加誘発・主なカード）でひらがな等の読みや一部表記から候補をサジェストし、手入力の手間を減らす（例: 「はるう」と入力すると「灰流うらら」が候補に表示される）。
- **リアルタイム連携モード**:
  - Phase 3 の画面認識と連携し、相手デッキが類推された瞬間に該当テーマの誘発カンペを自動で表示する。

### ③ 画面認識・戦績トラッカー

- **対戦ログ記録項目**:
  - 日時、**シーズン / イベント区分**（例: `2026-11 ランク戦`, `DC`, `フェス`）、**ランク帯**（任意: マスター1〜5 等）
  - **自分デッキ**（事前登録した自分のデッキから選択・維持。過去戦績を保持したままアーカイブ可能）
  - **相手デッキ**（誘発カンペ辞書からの選択に加え、未登録テーマや「不明」の自由入力も可）
  - **コイントス結果（表 / 裏）** と **実際の先攻 / 後攻**（コイン勝ち後攻選択などに対応するため分離して記録）
  - **勝敗（`WIN / LOSE`）**、自由メモ
- **戦績の可視化**:
  - 先攻／後攻別勝率、使用デッキ別勝率、対面テーマ別勝率、コイントス確率などの集計・グラフ表示（シーズン／イベント・使用デッキ等でのフィルタ対応）。
  - グラフは外部ライブラリを入れず、軽量な **自前 SVG / Tailwind バー** で実装する。
- **画面認識による自動トラック（Phase 3）**:
  - ブラウザの `getDisplayMedia` でマスターデュエルのウィンドウ映像を取得し、画面上の特定領域（ROI）を定期解析する。
  - **前提環境**: マスターデュエル **日本語 UI（OCR 言語 `jpn`）**、**16:9 解像度**をデフォルト ROI プリセットとし、画面上で相対座標（`0.0〜1.0`）を微調整可能にする。
  - **コイントス／先攻後攻の検知**: 進行中の対戦セッションに自動セットする。
  - **相手デッキ自動類推**: 画面左上のカード詳細ウィンドウや発動演出からカード名を OCR（Tesseract.js）＋あいまい検索（Fuse.js）で照合する。汎用カード（うらら・増G・指名者等、設定画面で編集可）および自分の使用デッキ名が誘発カンペ辞書（テーマ名・別名）と一致する場合の固有カードは自動除外し、**テーマ固有カードの信頼度閾値＋累積スコア**で相手テーマを判定してカンペを自動切替する。
  - **勝敗検知と確定フロー**: `VICTORY / DEFEAT` や降参メッセージ検知時に **登録確認ダイアログ** を表示し、勝敗・コイン・先攻/後攻・相手デッキ・メモを確認・補正した上で「はい」で登録する（「いいえ」時は編集内容を進行中フォームへ引き継いで手動編集へ戻せる）。手動記録ボタンも共通の確認ダイアログを経由する。

## 4. 開発ロードマップ（ボトムアップ型）

### Phase 0: 足場づくり・品質基盤構築（完了）

- リポジトリ初期化（`md-oretools` / Public リポジトリ ＋ Cloudflare Pages 本番・PR プレビュー配信開通）
- `AGENTS.md`（GitHub Flow・t-wada 4原則含む） / `docs/spec.md` / `docs/architecture.md` / `README.md` / `.github/pull_request_template.md` / `.agents/skills/add-feature/SKILL.md` 整備
- Vite + React + TypeScript（厳格設定）+ Tailwind CSS + shadcn/ui セットアップ
- 品質ゲート基盤（`npm` + `Biome` + `Vitest` + `Zod` + `lefthook` + GitHub Actions CI + SonarQube Cloud + Dependabot + `main` ブランチ保護 Ruleset）構築・疎通確認完了

### Phase 1: ポータル土台 ＋ 手札確率シミュレータ ＋ 誘発カンペ辞書（完了）

- 共通レイアウト（サイドバー／ナビゲーション、ダークモード基調のUI、将来のデュエルモード 2 ペイン切替を見据えたシェル設計）
- IndexedDB（Dexie.js）永続化基盤の構築
- **手札確率シミュレータ**の実装（排他グループ・DNF 条件式・厳密計算＋モンテカルロ自動フォールバック・プリセット保存）
- **誘発カンペ（辞書モード＆編集・保存機能）**の実装
  - 初期データとして代表的な環境テーマのテンプレートを用意（編集・初期値リセット対応）
  - 定番誘発の標準枠＋テーマ別の任意誘発追加機能
  - 各テーマに「別名（エイリアス）」と「自動類推用の固有代表カード名リスト」を持たせる

### Phase 2: 戦績トラッカー（手動記録・集計基盤）＆ PWA 化（完了）

- 自分のデッキ登録・アーカイブ機能
- 対戦ログ（日時、シーズン/イベント、ランク帯、自分デッキ、相手デッキ、コイン、先攻/後攻、勝敗、メモ）の永続化（IndexedDB）
- 勝率・対面相性・コイントス統計ダッシュボードの作成（軽量な自前 SVG / Tailwind バー）
- 全データの JSON エクスポート／インポート機能（Zod スキーマ検証・バージョニング・「全置換 / マージ」選択対応）
- PWA 化（`vite-plugin-pwa` による独立ウィンドウ起動・オフライン対応）

### Phase 3: 画面認識エンジン ＆ 誘発カンペ自動連携（完了）

- デュエルモード（戦績トラッカー＋誘発カンペの 2 ペイン同時表示ビュー）の実装
- `getDisplayMedia` を使った画面キャプチャコンポーネントの実装
- ROI（認識エリア）の座標設定・プレビュー機能（16:9 デフォルトプリセット＋相対座標の微調整）
- コイントス／先攻後攻／勝敗（降参含む）の自動検知と、登録確認ダイアログによる確定フロー
- 日本語 UI 向けカード名エリア OCR（Tesseract.js `jpn`）＋あいまい検索（Fuse.js）＋汎用/自デッキ一致テーマ除外・累積スコアによる相手デッキ自動類推
- 相手デッキ判定イベントから「誘発カンペ」パネルへのリアルタイム自動切り替え連携

## 5. 継続メンテナンス・今後の拡張候補

- **誘発カンペの環境更新**: 新パック・リミットレギュレーション改定に合わせて `scripts/check-meta-updates.mjs` 等で環境差分を確認し、テーマ・Tier・手札誘発カタログを定期更新する。
- **画面認識の精度・運用改善（必要時）**:
  - 16:9 以外の解像度（ウルトラワイド等）向け ROI プリセットの追加
  - 混合デッキ向けの「自分のデッキごとの採用カード除外リスト」登録機能
  - Tesseract.js 学習データの自前ホスト（完全オフライン動作・CSP 強化）およびバックグラウンド実行の安定化
